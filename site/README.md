# Conexão Solidária

Projeto acadêmico de Desenvolvimento Front-End para Web.
A ONG, os contatos e as campanhas são fictícios.

## Tecnologias

HTML, CSS e JavaScript, sem frameworks.

## Como executar

Baixe o repositório, extraia os arquivos e abra site/index.html
no navegador. Mantenha as pastas css, js e imagens dentro de site.

## Funcionalidades

- Páginas Início, Projetos e Cadastro.
- Sistema de design com variáveis CSS.
- Grid de 12 colunas, cinco breakpoints e componentes com Flexbox.
- Menu responsivo com submenu e botão para dispositivos móveis.
- Máscaras de CPF, telefone e CEP.
- Mensagens de validação, etiquetas e modal demonstrativo.

## Limitações

O formulário não envia nem armazena dados.
CPF, telefone e CEP são verificados apenas quanto ao formato.
Use dados fictícios nos testes.

## Versionamento

main contém a base estável.
develop reúne as alterações em desenvolvimento.
Branches feature/* são destinadas a alterações específicas.
